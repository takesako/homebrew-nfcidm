# Takesako Nfcidm

## How do I install these formulae?

`brew install takesako/nfcidm/<formula>`

Or `brew tap takesako/nfcidm` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "takesako/nfcidm"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
